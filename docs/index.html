Curling schedule → calendar

Turn your RCN (Navy) Curling Club personal schedule into a file for Google Calendar, Outlook or Apple Calendar.

1. Get your schedule PDF

  1. Sign in at curlnavy.com and open My Schedule.
  2. Choose Print, then Save as PDF.

2. Drop it here

Game timeLeagueRdFlightLocVersus

🔒 Your PDF is read right here in your browser. Nothing is uploaded or stored. All times are Ottawa time. The schedule only lists start times, so the end time is the start plus the game length above. Each event's notes include every column from the schedule.

3. Import it

  1. Google Calendar: on a computer, Settings → Import & export → Import, and pick the file.
  2. Outlook: open the file, or File → Open & Export → Import/Export.
  3. iPhone / Mac: open the downloaded file and tap Add All.

Got an updated schedule later? Import the new file. Most calendar apps update the existing games instead of duplicating them. A game that moved to a new time will appear as a new event, so delete the old one.
